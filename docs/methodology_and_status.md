## Daily recurring automation — política de solo-borradores (vigente desde 2026-09-01)

Scheduled task **"NODOTO — Cold Outreach Diario (9am Bogotá)"** (cron `0 14 * * *` UTC = 9:00am Bogotá). Ninguna corrida (automática o manual) envía correo directamente: todo — follow-ups y primer contacto — se crea como borrador Gmail (`GMAIL_CREATE_EMAIL_DRAFT`) para revisión y envío manual de Andrés. Cada corrida: (0) revisa rebotes (`from:mailer-daemon`) y actualiza `sent_tracking.csv` + `known_bad_contacts.csv`, (1) crea borradores de follow-up para leads elegibles (excluyendo BOUNCED, ~4 días desde el último paso), (2) descubre y verifica leads nuevos deduplicando contra `bogota_leads.csv`, `sent_tracking.csv` y `known_bad_contacts.csv`, con chequeo de MX obligatorio, (3) genera copy + HTML por el playbook, (4) crea borradores Gmail round-robin, (5) actualiza los 3 archivos CSV y este documento. **No usa ningún servicio de pago.**
